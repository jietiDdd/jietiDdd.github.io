# Chart Studio / 数据可视化工作台

独立静态页面，与 `/rank/` 一样部署在博客域名的子目录 `/charts/`。无需构建或后端。

- 表格单元格编辑，添加 / 删除行列，逐行勾选。
- CSV（UTF-8、GBK / GB18030）、TSV、Excel XLSX / XLS 导入，可切换 Excel 工作表。首行作为列名，支持 5 MB、500 行数据、30 列。
- 选择分类列及多个数值列，分类求和 / 平均，按任意数值列（包括未绘制的列）、行合计、行均值、名称排序，截取前 N 行。
- 条形、柱状、折线、饼图、环形图及表格。饼图与环形图使用首个勾选的数值列，不接受负数。
- 主题、列颜色、分类配色、均值、数值阈值、占正数合计的比例阈值、数值渐变、自定义多档分段配色；内置常用色板适用于背景、各列、条件色及每个分段；标题、背景、尺寸、字号和精度可调。
- PNG / SVG 图片导出、筛选后的 CSV 导出、JSON 项目备份与恢复。过长图表请导出 SVG 或减少可见行数。
- 本地自动保存，不上传数据。CSV 导出对公式前缀添加单引号，避免被表格软件作为公式执行。

## 数据语义

空白 / 非数字作为缺失值；不会补零。均值忽略缺失值。折线遇缺失值断开。聚合先于排序，排序先于前 N 行截取。条件颜色的统计范围为最终可见数据，各数值列独立计算。占比为 `max(值, 0) / 本列正数合计`。百分数按小数参与计算，例如 `25% = 0.25`，可调整小数位数。

## 自定义分段配色

选择“着色规则 → 自定义分段配色（多档）”。分段依据支持原始数值、百分数本身（`25%` / `0.25` 对应 25）、占本列正数合计的比例。按从小到大填写分界点（最多 100 个），每档独立选色，最后一档自动覆盖剩余范围。可以添加或删除分界点。

例如分界点 `25、50、75` 生成 `<25`、`25≤值<50`、`50≤值<75`、`≥75` 四档，等于边界值归入下一档。图例与 PNG / SVG 一起导出；项目保存包括排序列、档位和各档颜色，兼容此前的项目文件。

## 验证

在仓库根目录运行 `node --test charts/core.test.cjs`，语法检查 `node --check charts/app.js`。本地预览：`python -m http.server 8765`，访问 `/charts/`。

Excel 使用随仓库保存的 SheetJS CE 0.20.3，来源 https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.full.min.js ，授权见 `vendor/LICENSE`。页面没有外部运行时依赖。

此仓库是 Hexo 生成后的站点。如上游重新生成并覆盖整个仓库，应在 Hexo 源项目的 `source/charts/` 同步保留这些文件，并在 `_config.yml` 的 `skip_render` 中加入 `charts/**`；导航入口也应同步到主题配置。仓库中没有 Hexo 源配置，故本次仅修改发布站点。

## 颜色叠加规则

默认“主题 / 自定义列色 → 基础颜色 → 条件深浅”。按列保留色相，按均值、阈值、占比、渐变或多档规则改变色深。每档色深可单独调整（5–100%）；100% 为基础色，越小越浅。主题变化保留自定义列色；“恢复主题列色”清除自定义色。图例同时显示列色和条件深浅。

若需要各列共用任意指定的条件颜色，可显式选择“用指定条件颜色替换基础颜色”，此时基础色相关控件停用并说明原因，切回保留基础颜色即恢复。此前项目的分界点和条件颜色仍保留，默认使用叠加模式。

原始数值 42 在百分数模式下为 4200%；以 0–100 存储的百分数应选“原始数值”，仅以 0–1 或带 `%` 输入的数据使用“百分数本身”模式。

## 相对均值 / 中位数分段

分段依据支持“占本列正数合计”“相对本列平均值”“相对本列中位数”。后两者均以平均值 / 中位数为 50% 中心，使用 `数值 / 参考值 × 50%`，50% 对应参考值，参考值的 2 倍为 100%，允许超过 100%。均值 / 中位数按最终可见数据分列计算，忽略空白和非数字；偶数个值取中间两项的平均。参考值为零或无有效数据时，比值不可计算，以灰色显示并提示。负数按有符号比值计算。图例说明具体计算依据。
