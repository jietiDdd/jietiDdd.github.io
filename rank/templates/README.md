# 榜单模板发布与管理

此目录存放公开模板。每个 `.html` 文件是独立网页，包含分类、待填条目及完整图片数据。朋友打开 `https://jietiddd.github.io/rank/templates/文件名.html` 即可填写，结果只保存在对方浏览器。

## 新增

1. 打开 [榜单编辑器](https://jietiddd.github.io/rank/)，编辑好标题、分类、条目与图片。
2. 点击「发布待填模板」，输入英文链接名称，下载 `名称.html`。
3. 在本目录使用 GitHub 的 **Add file → Upload files** 上传它，并提交更改。等待 Pages 更新后，访问编辑器给出的地址检查。

发布文件使用当前编辑器中的图片数据，不会因为分享再次压缩。发布时所有条目自动放在「待分类」，不会带上你的排序。

## 更新或删除

在 GitHub 中更新相同文件名的内容即可保留分享地址；删除对应 `.html` 文件即可撤下。建议先备份文件。已打开过该模板的朋友可能在自己的浏览器中保存了填写结果，更新模板不会自动覆盖他们的数据；他们可点击「重新载入原模板」从新版开始。GitHub 的提交历史可用于查看与恢复旧版。

本目录中已有的 `.json` 是旧链接的数据备份，不再是新模板网页的依赖。
